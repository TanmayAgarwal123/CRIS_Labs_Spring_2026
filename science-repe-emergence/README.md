# science-repe-emergence

Representation Engineering on Qwen3 base models to test whether scientific
reasoning representations become more linearly readable, robust to paraphrase,
and steerable across model scale.

See `AGENTS.md` for the full spec and `CLAUDE.md` for the active sprint scope.

## Quick start

```bash
pip install -r requirements.txt
cp .env.example .env  # fill in OPENAI_API_KEY and HF_TOKEN
```

Pipeline (full command sequence is in `AGENTS.md` under "Command Sequence").
